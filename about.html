About this site

This interactive dashboard contains information about food access for higher education institutions in Erie County, NY.

NoteNote on AI use

Although this project does not include components of AI data outputs, some code chunks were created with the “help” of Perplexity AI.

Even though I personally do not encourage using AI in your daily tasks and refrain from using it in my daily life, I used Perplexity AI as a learning tool and as a testing ground to experiment with some of the ideas I have for this project as a complete beginner.

Any output was checked against existing public resources like R-Bloggers, Stack Overflow, Posit Community, rOpenSci, and RProject subreddit. For visual display references, I used Quarto’s official guide.

If you like any aspect of this project, I would highly recommend triple checking my data and resources before incorporating them into your own project.

Thank you!
